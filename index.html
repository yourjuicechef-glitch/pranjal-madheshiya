The AI Integration practice

AI pays off when it is part of the system, not bolted beside it. I take models into the stacks I have run for a decade — same auth, same pipelines, same monitoring, measured in production.

  1. 01

    LLMs in production

    Azure OpenAI, AWS Bedrock, OpenAI and Claude APIs wired into .NET 8 and Node.js services — streaming, retries, rate limits and per-feature cost budgets.

    Azure OpenAI · Bedrock · Semantic Kernel
  2. 02

    RAG over company data

    Retrieval on the databases teams already run: embeddings in PostgreSQL pgvector or Azure AI Search, chunking, citations, and answers grounded in the source.

    pgvector · Azure AI Search · Embeddings
  3. 03

    Agents & tool calling

    Function calling and MCP servers that expose internal REST APIs to models through the same RBAC middleware — the model can only do what the user could.

    MCP · Function calling · RBAC
  4. 04

    Secure by design

    Prompt-injection guards, PII redaction, keys in AWS Secrets Manager / Key Vault, OAuth on every hop, and an audit log of each model call.

    OAuth · Secrets · Guardrails
  5. 05

    LLMOps in the pipeline

    Prompts versioned in Git, eval suites run in YAML CI/CD on every pull request, blue-green rollout of model changes, tokens and latency in Datadog.

    Evals · CI/CD · Datadog
  6. 06

    AI-accelerated delivery

    Copilot and Claude Code in the team workflow with human code-review gates — faster sprints without lowering engineering standards.

    Copilot · Claude Code · Code review
